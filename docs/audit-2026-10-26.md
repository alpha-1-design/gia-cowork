## 10. Chat audit — verified findings

Source-level audit of `ChatModule.tsx`, `useChatState.ts`, `useChatGeneration.ts`, `useGiaStore.ts` and their tests. These are pre-existing defects, not regressions from the redesign.

| # | Severity | Finding | Evidence |
|---|---|---|---|
| C1 | **Critical** | **Branching is broken.** No production code ever sets `parentId`, so the message "tree" is flat. `addBranch` clones one message and switches `currentBranchId`; `getBranchMessages` then filters by branch id and every earlier message disappears. `forkSession` produces a one-message session. | `useGiaStore.ts` (`addBranch`, `getBranchMessages`); no `parentId` assignment outside tests. |
| C2 | **Critical** | **Editing a user message deletes the wrong turn.** The edit path treats the user id as an assistant id and removes `[previous message, edited message]`, leaving the answer to the edited message in place. | `useChatState.ts:463-466`. |
| C3 | **High** | **BUILD mode never sends its builder prompt.** `buildBuilderPrompt` is imported but never called, and `modePromptFor('build')` returns `''`. The skill gate and "finished means it runs" checklist never reach the model. | `ChatModule.tsx`, `modePrompts.ts`. |
| C4 | **High** | **"Toggle thoughts" is a no-op.** It sets `Set(['all'])`, but every consumer checks `showThoughts.has(msg.id)`. | `useChatState.ts`, `MessageList.tsx`. |
| C5 | **High** | **Queue/steer is unreachable.** The composer is disabled while loading, so the enqueue branch never runs; `QueuedMessages`, `SessionSwitcher` and `AgentActivityStrip` are imported only by their tests. | `ChatModule.tsx` composer guard. |
| C6 | **High** | **WorkLog fabricates timings.** Per-step `startedAt`/`endedAt` are computed as `Date.now() - steps.length*200/100` and then displayed as real timings. | `WorkLog.tsx`. |
| C7 | **Fixed in this pass** | **Mic opened a separate voice assistant.** `VoiceMode` called `GiaBrain` directly and never wrote to the chat session. It now loads the active thread as history and appends each exchange to that session. | `VoiceMode.tsx`. |

Verified working: send, Stop/Esc abort, New Chat, message delete + 5 s undo, model selection persistence, attachments reaching the request, templates, knowledge panel, copy/retry/continue.
